# Code of Conduct

We want Job Application MCP to be a technical community where people collaborate respectfully, discuss trade-offs honestly, and improve the project together.

Contributors are expected to:
- Be respectful and professional.
- Assume good faith while still asking for evidence and reproducible results.
- Focus technical criticism on the work, not the person.
- Welcome different levels of experience.
- Keep discussions relevant to the project.
- Protect user privacy and never post credentials, tokens, resumes, or private application data.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, deliberate disruption, publishing private information, or knowingly submitting malicious code.

Maintainers may remove comments, close discussions, reject contributions, or restrict participation when this code is violated.

For security-sensitive or private concerns, use [SECURITY.md](SECURITY.md) rather than posting details publicly.
